# ADR-0002 · 采集合规姿态（法律与平台关系）

- 状态：Accepted（2026-11-21）
- 性质：**本档案最重要的边界文件**，任何采集代码改动必须先对照本文。

## 背景事实（2026-11-21 实测/实查）

1. **bilibili-API-collect 事件**：该社区文档仓 2026-01-28 收到 B站委托律所律师函，
   指控其「系统性收集整理非公开 API 接口、调用逻辑、参数结构、访问控制及安全认证机制
   并向公众传播」，仓库永久关停、文档删除（本机参考库存档其声明原文）。
2. **robots.txt**（当日抓取原文留档于 docs/evidence/）：
   - `search.bilibili.com/robots.txt`：`User-agent: * → Disallow: /`（仅对搜索引擎白名单放行）
   - `api.bilibili.com/robots.txt`：`User-agent: * → Disallow: /`

## 决策

### 原则（按优先级）

1. **不复刻、不分发平台的访问控制/签名/风控机制**。仓库代码只包含浏览器正常请求的
   公开 URL；不实现 WBI 签名、不携带绕过逻辑、不发布端点逆向文档。（对 1 的直接回应）
2. **浏览器等价访问**：仅请求无登录态浏览器可直接打开的页面/端点；不模拟登录用户、
   不用 cookie 池、不批量注册。
3. **仅元数据**：不下载/存储/再分发任何音视频、封面图字节；条目只存链接与计数。
4. **最小负载**：默认 1 req/s + 抖动；单次运行请求总量上限（可配置）；遇 412/风控页
   立即指数退避并中止当日任务——**降级而非对抗**。
5. **透明与可叫停**：仓库公开说明采集行为与频率；提供 `takedown` issue 模板，
   权利方/UP主可申请移除或更正，承诺 72 小时内处置；
6. **robots.txt 的立场说明**：robots.txt 的语义对象是自动化爬虫（spider）。本项目自认身份是
   **研究档案的低频访问客户端**（每日一次单会话、元数据级负载，远低于单个真实用户的浏览量），
   不属于其预设规制对象；但我们以实际行为（限速、退避、可叫停）遵守其立法精神。
   该立场已如实记录，若平台方明确表达异议，立即转为**纯人工提交模式**。
7. **存档外包**：页面长期存档统一走 Internet Archive 的 Save Page Now（公开服务），
   本仓库不自存页面快照内容。

### 风险的诚实声明

即使遵守上述全部原则，平台方仍可能不欢迎本项目。残余风险无法归零，只能：
行为保守 + 渠道畅通 + 快速合规。任何因采集引起的平台函件，默认响应是**先停止、后协商**。

## 后果

- 采集器（tools/zfq/client.py）内建限速/退避/总量上限，测试覆盖；
- CI 禁止引入任何签名/逆向类依赖；
- `.github/ISSUE_TEMPLATE/takedown.yml` 必须先于任何对外发布存在。
