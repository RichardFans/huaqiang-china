# ADR-0004 · 站点技术选型

- 状态：Accepted（2026-11-21）

## 决策

静态站点用 **Astro 5**（本机 Node 22.20 实测可用），纯静态输出到 GitHub Pages。

## 理由

1. 任务书约定「Astro 或 Hugo」；本机无 Hugo 二进制、有 Node 22，Astro 落地成本最低；
2. 数据驱动页面（多切面视图由同一数据源生成）在 Astro 的 `src/pages` + JSON 数据注入
   模式下最直接，Hugo 的主题/模板体系对「数据文件→多切面页面」的映射更绕；
3. 站点层**零采集逻辑**：所有数据由 Python 管线生成到 `site/src/data/`，
   站点只消费——采集合规边界（ADR-0002）不被前端依赖污染；
4. 备选「Python 自研生成器」落选：偏离任务书且引入第二套模板体系，维护面更宽。

## 后果

- CI 分两段：Python 管线（数据校验）→ Node 构建（站点）；数据不变时站点构建可跳过；
- 本地预览端口须避开 5173/3000/8080 等默认冲突带（全局端口台账约定），
  统一用 `4321`（Astro 默认）并在台账登记。
