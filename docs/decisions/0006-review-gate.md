# ADR-0006 · 评审门控（review gate）

- 状态：Accepted（2026-11-21）
- 背景：首轮真实采集（5 关键词 × 首页，收录 124 条）暴露两个语料质量问题。

## 实证发现

1. **检索相关性污染**：B站搜索按 title+简介+标签做相关性匹配，非征服主题作品也会命中
   （例：《我的数学老师会玩原神》《我把杰哥不要做成了跑酷游戏》《特效小哥大战建模小哥4》）。
   这些作品可能仅在标签/简介提及买瓜，甚至只是相关性噪声。
2. **形态自动判定偏弱**：空格标题的鬼畜名作（「无 伤 反 杀 刘 华 强」式）被判为 clip；
   中文紧邻「AI」因 \b 词边界失效而漏判（「能控制AI」）。

## 决策

1. schema 增加两级复核状态：
   - `scene_status: auto|confirmed`（auto 必须留 scene_evidence）
   - `review: pending|confirmed`（**整条人工复核**；confirmed 的前提是 form 与 scene 均 confirmed）
2. 标题显式命中桥段词（买瓜/保熟/宋老虎/封彪等）→ scene 直接 confirmed（标题即一手线索）；
   仅检索词相关命中 → auto + 低置信标注「复核优先」。
3. 形态启发式修正：AI 去词边界、新增空格标题→guichu 启发（仍标 auto）。
4. 所有呈现层（站点/列表/报告）必须给 pending 条目打「⚠ 待复核」徽标——
   **未复核数据可以展示，但不得冒充确认事实**。
5. 复核操作走 `zfq.review` CLI 或 issue 评审，动作留痕于条目 evidence 字段。

## 后果

- 自动化永远不产生「确认」；确认只能来自看过的（机器或人）评审动作；
- 语料纯净度是渐进指标：confirmed 占比公开显示在站点关于页。
