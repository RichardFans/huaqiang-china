# ADR-0003 · 命名规范与国际化

- 状态：Accepted（2026-11-21）

## 决策

1. **站点界面名（用户可见）**：中文主名 **「征服二创宇宙档案」**；英文副题
   *The Conquest Remix Archive*（用于国际推广的辅助称谓，不顶替中文名）。
   候选落选记录：「华强宇宙档案」（以角色名代剧名，窄化语料）、「征服鬼畜志」
   （鬼畜只是形态之一）。
2. **代号边界**：仓库/包名/路由前缀用 `huaqiang-china`（仅代码层）；
   界面、文档、对外材料一律中文名。slug 体系见 data/vocabulary.md。
3. **双语策略**：中文为第一语言（一手研究语言），英文页为**编译产物**——
   不是机器直译，术语走 docs/glossary.md 的固定对照表；文化注释框（"保熟"语境、
   鬼畜谱系）为英文页独有内容。
4. **专有名词对外翻译**：刘华强 → Liu Huaqiang；《征服》 → *The Conquest* (2003)；
   买瓜 → the watermelon scene；鬼畜 → guichu (remix genre，保留拼音加注)；
   音MAD → yin-MAD (music video montage)。新增术语先入 glossary 再上页面。

## 后果

- 站点 i18n 结构必须中英两套内容源，而非一套文案两个词典；
- 术语表是治理文件（PR 变更），不是页面装饰。
